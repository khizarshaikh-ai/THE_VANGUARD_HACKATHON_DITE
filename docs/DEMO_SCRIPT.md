# ClassPulse — 4-minute demo plan

Use only the features that actually work on your deployed instance. Clearly identify fictional sample responses. Do not reveal passwords, keys, account pages or personal tabs.

## 0:00–0:25 — The problem
“Teachers often hear from the students willing to raise their hands. ClassPulse makes room for every short answer, including uncertainty, and helps the teacher decide what to explain next.” Show the home page.

## 0:25–1:05 — One real answer travels
Open Teacher studio and create a new room. Open its student link in a separate private window. Submit a short answer and select confidence. Return to the teacher room and show the answer arriving. No student name is requested.

## 1:05–2:00 — Reveal evidence
Open the explicitly labelled sample classroom, which contains eight fictional responses. Close the round and choose Reveal patterns. State the actual mode: “This run uses local TF-IDF and K-means to cluster wording” OR “This run uses Gemini to suggest groups of reasoning.” Do not mix the claims. Open a pattern to show the original answers. Counts come from validated IDs, not guesses.

## 2:00–2:45 — Teacher decides
Explain that grouping is not grading. Read the evidence, write a review note and mark reviewed or rejected. In Local ML mode, explain that similar words can hide opposite meanings. The teacher’s review is essential, not a decorative button.

## 2:45–3:20 — Close the loop
Edit the follow-up question and its expected reasoning. Open the next round. Submit a second answer from the student window. Show both snapshots. Say these are descriptive counts and self-reported confidence, not demonstrated learning improvements.

## 3:20–3:45 — How it works
“Flask and SQLite share responses between browsers; the analysis module groups them; every group links back to evidence. We tested the response, access-control, validation and round-isolation flows.” Mention only tests actually run. Note that production would need durable hosting, stronger account management and institutional privacy decisions.

## 3:45–4:00 — Close
Show the public app URL and repository URL if they exist. “ClassPulse helps a teacher see the room, inspect the evidence and choose the next question.” Keep the complete video between three and five minutes.
