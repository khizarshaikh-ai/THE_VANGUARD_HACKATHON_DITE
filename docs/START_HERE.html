From folder to classroom.

This is the guide for the actual Flask app. It replaces the Streamlit installation path in the earlier planning PDF.

1. Install Python

Download Python 3.13 or 3.14 from python.org. On Windows, enable “Add Python to PATH” if offered. Finish the installer before continuing.

2. Extract the whole ZIP

Right-click the ZIP and choose Extract All on Windows, or double-click it on Mac. Open the extracted ClassPulse folder. Keep app.py, templates and static together.

3. Start the app

  • Windows: double-click START_WINDOWS.bat.
  • Mac: open START_MAC.command. If double-click is blocked, open Terminal in this folder and run zsh START_MAC.command.

The first run downloads packages. Wait for it to finish. Choose a private teacher password when asked. Your typing is hidden on purpose. Type it, press Enter, then repeat it.

4. Open the browser

Visit http://localhost:8765. Keep the terminal open. Choose Teacher studio and enter your password.

5. Try the full flow

  1. Click Explore a sample class. Its eight answers are fictional and labelled.
  2. Click Copy link. Open a private/incognito browser window and paste it.
  3. Type an answer and choose your confidence. Press Send.
  4. Return to the teacher page. The response count updates within a few seconds.
  5. Click Close this round, then Reveal patterns. Local ML works without a key.
  6. Open the original answers under a pattern. Write your interpretation and mark reviewed.
  7. Edit and open the next round. Add an expected answer before opening it.
  8. Return to the student window. The new question appears automatically.
Know what the AI does. Local ML groups similar words; it cannot certify understanding. Gemini mode is optional and requires a private API key on the server. Never describe a local run as a live Gemini result.

6. Share and present

Use README.md for public deployment. Use docs/DEMO_SCRIPT.md for a four-minute presentation. Source ZIP sharing does not create the required public website, repository or Drive video link. Verify each separately.

If something fails

Read the last terminal error. If Python is missing, install it and reopen the terminal. If the server is already using port 8765, stop the earlier window with Ctrl+C. To change a forgotten local teacher password, run python setup.py using the environment’s Python, then restart the app. Do not delete the entire project.
